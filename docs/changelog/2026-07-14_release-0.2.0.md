# Release 0.2.0

**Date:** 2026-07-14
**Type:** release (minor)

First versioned release after the MCP-first cutover. Rolls up the changes merged since `0.1.1`; version bumped across `pyproject.toml`, `installer/src/konecty_skills/__init__.py`, `.claude-plugin/plugin.json`, and `.claude-plugin/marketplace.json`.

## What's in it

- **Plugin + marketplace distribution** — install with no terminal via `/plugin marketplace add konecty/skills` → `/plugin`. Bundles the 4 skills; no MCP server URL baked in (konecty-setup registers it per company).
- **Admin MCP defaults to OAuth** — installer and `konecty-setup` lead with the trusted-client OAuth path; OTP → Bearer is an explicit fallback (`--admin-auth otp` / older Konecty).
- **konecty-setup correct across environments** — OAuth-by-environment matrix (CLI + desktop app → `/mcp` Authenticate; claude.ai web → Connectors; headless → `--no-browser` paste or Bearer token); no more "use the terminal" dead-end when running headless.
- **Installer robustness** — sends a CLI User-Agent (WAFs 403 the default `Python-urllib`), unblocks admin OTP behind Konecty's strict-CORS zone (`Sec-Fetch-Site: none`), normalizes Brazilian phones to E.164, and the well-known probe flags a bad OAuth issuer.
- **Packaging** — `pyproject.toml` at the repo root so `uvx --from git+…` resolves.

## How installed clients update

- **uvx installer**: `uvx --from git+https://github.com/konecty/skills konecty-skills update` — re-fetches skills from `main` with SHA-256 protection (local edits preserved). Content-driven; no version check.
- **Plugin**: marketplace auto-update, or `/plugin` → update — surfaced by the bumped `plugin.json` version.
