# Release 0.3.0 — OAuth-only (OTP purge) + new upload/delete contracts

**Date:** 2026-07-22
**Type:** release (minor, **breaking** for the installer's admin fallback)

Version bumped across `pyproject.toml`, `installer/src/konecty_skills/__init__.py`, `.claude-plugin/plugin.json`, and `.claude-plugin/marketplace.json`.

## Breaking

- **Installer: `--admin-auth otp` removed.** The OTP→Bearer admin fallback and the
  interim admin-token storage (`KONECTY_TOKEN`, `~/.konecty/.env` login flow) are
  gone. The only admin path is OAuth via a trusted client (`OAUTH_CLIENTS_JSON`,
  e.g. `claude-code-admin`) — ADR-0011/ADR-0020 upstream. `credentials.py` now only
  caches the company URL; doctor's Bearer-token check was removed. Installer suite:
  197 tests green (the 30 removed tests exercised the deleted OTP/Bearer paths).

## Skills — OAuth is the only documented path

- **konecty-data / konecty-meta / konecty-setup**: total purge of OTP instructions
  and `authTokenId` mentions. The `session_*` tools no longer exist upstream
  (ADR-0020); auth is the standard OAuth handshake done by the MCP host. 401
  recovery = reconnect/re-authorize the MCP server. Troubleshooting for "no consent
  screen / no browser" now points to backend upgrade or trusted-client provisioning.
- `konecty-meta/references/namespace.md` keeps `otpConfig` (Konecty UI login config,
  unrelated to MCP auth) with a clarifying note. `konecty-dev` untouched
  (server-side service-account auth, out of scope).

## New upstream contracts documented

- **`file_upload` (user MCP) — single-use upload URL** (Konecty ADR-0013): the tool
  returns `uploadUrl`/`expiresAt`/`method`/`maxFileSize`; bytes go over HTTP
  multipart directly, never through the MCP. Chat-only hosts cannot upload
  (documented limitation). `konecty-data/references/files.md` rewritten; e2e
  rewritten to POST real bytes and assert the single-use 410.
- **`meta_delete` (admin MCP)**: the "no deletion tool" gap is closed.
  `konecty-meta/references/remove.md` rewritten around the two-step contract
  (dry-run blast radius → `confirm: true`), `MetaObjects.Trash` recovery, and the
  children → hooks → primary order. Tool inventory now lists 13 tools.
- E2E harness ref moved to `feat/admin-mcp-meta-delete` (contains both features);
  re-verify and move to `main` after the Konecty PRs merge.

## How installed clients update

- **uvx installer**: `uvx --from git+https://github.com/konecty/skills konecty-skills update`.
- **Plugin**: `/plugin marketplace update konecty` → `/plugin` → update.
