# Release 0.2.1

**Date:** 2026-07-14
**Type:** release (patch)

Ships the change merged since `0.2.0`; version bumped across `pyproject.toml`, `installer/src/konecty_skills/__init__.py`, `.claude-plugin/plugin.json`, and `.claude-plugin/marketplace.json`.

## What's in it

- **konecty-setup autonomous MCP registration (CLI + app)** — the skill no longer dead-ends when the `claude` CLI is absent (typical in the desktop app). It detects the environment (`command -v claude`) and registers on its own: CLI → `claude mcp add --scope user` (replace-not-duplicate); app → a safe `python3` write into `~/.claude.json` (missing file → `{}`, preserves all other keys, replaces only the `konecty`/`konecty-admin` entries). OAuth stays the default; Bearer/OTP is the labeled fallback.

## How installed clients update

- **uvx installer**: `uvx --from git+https://github.com/konecty/skills konecty-skills update` (content-driven; SHA-256 protection).
- **Plugin**: `/plugin marketplace update konecty` → `/plugin` → update (surfaced by the bumped `plugin.json` version `0.2.1`; same version string would be skipped).

## Note

The desktop-app `/mcp` → Authenticate OAuth UX is documented but not yet empirically verified by us; the skill flags this and offers the Bearer fallback as the guaranteed no-browser path. A follow-up release will remove that caveat once verified.
